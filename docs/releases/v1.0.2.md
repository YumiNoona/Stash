# Stash 1.0.2 - More room for your files

- Import any file type through Files, including PNG, JPG/JPEG, HEIF/HEIC, PDF, WebP, GIF, BMP, AVIF and Office documents.
- Detect image/PDF headers and common extensions when providers supply missing or incorrect MIME labels. A photo named `.img` can preview when its content is a supported image.
- Preview HEIF/HEIC and AVIF using the offline Android decoder on compatible devices, with bounded memory and correct orientation. Original files remain intact.
- Read TXT, Markdown, CSV, JSON, XML and other text documents inside Stash, including Unicode BOM handling. HTML is displayed as plain text.
- Store, share and download other formats as original files. Unsupported or locked previews explain that the original is still available. Mixed-file documents keep all originals in ZIP exports.
- Download or share each untouched original from file information, including individual pages of a multi-file document.
- Consistent format detection across import, saved pages, OCR, thumbnails, sharing and downloads.

Android 8.0+. HEIF/HEIC and AVIF previews depend on Android version and available codecs; see the format guide in the repository. Existing 20-file/24 MB document and 64 MB vault limits still apply.

Optimized, non-debuggable production APK signed with the same key as v1.0.1. Updates from v1.0.1 install normally. The refreshed v1.0.0 used a different key; see the migration guide before replacing it. Never uninstall without an exported and verified portable backup.

Validation: 86 unit tests and six Android device tests passed. Real-file checks cover PNG, JPG/JPEG, GIF, WebP, BMP, HEIC, AVIF, image headers under an `.img` name, rotated JPEG/HEIC, two-page and damaged PDFs, text/Office/binary originals and lossless mixed-file ZIP exports. Release build and lint passed with zero errors.
