# Stash v1.0.0 — refreshed release

A private space for cards, documents, identity details, passwords and notes. Stash works offline, stores vault records in encrypted app-private storage and starts with an empty vault.

## What is included

- Camera scans, photo and file import, local text recognition, multi-page document review, edge correction and redaction before sharing.
- Card artwork, folders, custom tags, search, widgets and light/dark backgrounds.
- Passphrase-protected portable encrypted backup and user-directed readable exports.
- In-app privacy policy, no account, no ads, no analytics and no internet permission.

The APK is a non-debuggable, optimized release for Android 8.0 and newer. The `.sha256` file beside it verifies the download.

## For earlier Stash installs

This refreshed v1.0.0 APK uses a new signing key. Android cannot install it over the earlier v1.0.0 GitHub APK, even though the visible version number is unchanged. Before removing an older installation, export and verify copies of every record and original file you need. The earlier v1.0.0 build did not have portable backup. Its device-bound encrypted backup cannot restore after uninstalling because the original Android Keystore key is deleted with the app. Uninstalling also deletes the local vault. Keep readable exports private.

For new installations, use the portable encrypted backup when moving to another device or reinstalling. Keep both the backup file and passphrase safe.
