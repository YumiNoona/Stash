# Stash v1.7.1

- Protect Home card downloads with a masked default, a separate full-number opt-in and fresh device authentication. Never include CVC. Apply authentication and case-insensitive private-field filtering to readable Settings exports too.
- Route Home attachment downloads through the shared error-handled exporter; unavailable destinations and write failures show an error instead of crashing.
- Fix crop handles cancelling their own gestures and dragging the sheet. Validate corner order and calculate perspective output sizes using pixel distances.
- Treat file and camera appends as one busy draft operation. Ignore stale results, preserve existing pages/title on failure, and enforce the same 20-file / 24 MB limits for every import path.
- Finish the saved-document page editor: add files or scans, correct edges, rotate, reorder and remove pages, undo the latest change, and save once. Cancelling preserves the saved original.
- Redact across every image/PDF attachment in a document and share one flattened copy with all pages retained in order. Abort on an unreadable page instead of omitting it. Redaction supports up to 100 pages.
- Sample custom backgrounds before bitmap allocation, respect EXIF orientation, bound dimensions/input size, and stage an atomic image before switching preferences. Failed imports preserve the previous background.
- Preview the selected Light/Dark background target, avoid unrelated preference reloads, and improve readability over custom photos.
- Use consistent folder naming rules in Organization and Move. Serialize vault writes and prevent backup/restore operations overlapping edits or being dismissed midway through restore. Update the scope documentation.

Validation: 52 JVM tests pass; debug APK builds; Android lint has 0 errors (47 warnings and 6 hints remain). Android emulator checks used fabricated documents: continuous crop dragging without sheet movement; 100 MP photo sampled to 1250 x 1250; failed image import preserving background preferences; saved-document append, undo, cancel and save; four-page redacted PDF retaining page order with selected text visibly covered and no underlying text layer.

The APK uses the same local debug signing identity as earlier Stash releases for update compatibility. Device-bound encrypted backups remain device-bound; portable recovery and separate encrypted attachment storage are future work.
