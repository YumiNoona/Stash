# Stash v1.6.1

- Give dark mode its own full-screen indigo aurora glass artwork, with cyan, violet and rose reflections. The original light artwork remains available in light mode.
- Float the home profile/name and settings controls over scrolling content. Apply shared translucent headers to cards, documents, settings, profile, information, entry/review forms, search, NFC and camera screens.
- Start document viewers with controls hidden. Tap the image to show or hide them; controls fade out after 3.5 seconds without interaction. Preserve page swiping, zoom, accessible control toggles and PDF navigation. Keep controls visible while a dialog or scan needs attention.
- Centre the four document tools within their glass toolbar with equal top and bottom padding.
- Enter document selection with zero selected. Selecting a card no longer adds rows or changes its height. Show the count and Select all, Move, Download, Delete and Close icons in one compact floating bar. Selection stays active when its count returns to zero and drops records excluded by filters.
- Remove Basic from the artwork carousel. Skip can still create a basic card and existing Basic cards continue to display correctly.

Validation: 36 JVM tests; Android lint; Android 15 emulator checks for zero-to-one selection without card movement, document tap/show/tap/hide and timed hiding, multi-page swiping, dark/light themes and floating headers. Generated artwork resource and the full built-in imagegen prompt are recorded in `docs/dark-background-source.json`.

The APK uses the same local debug signing identity as earlier Stash releases and updates existing installs without clearing their data.
