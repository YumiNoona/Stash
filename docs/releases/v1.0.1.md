# Stash 1.0.1 — Everyday reliability

This update fixes several interruptions in everyday use while preserving existing vaults and the current interface.

- Save, edit and delete operations release their busy state immediately after the vault write, so confirmation messages no longer block navigation for several seconds.
- Notes can now edit their text, and password entries can edit the website, username and password after device unlock. The password editor closes when authorization is lost.
- Profile photos respect camera rotation and mirroring. Photo imports and document previews check their dimensions before allocating pixels; rotated previews fit their intended bounds.
- Profile imports are bounded to 32 MB. Oversized vault files are rejected during reading rather than loaded completely before validation.
- Copying the same private value again gets a fresh 30-second clipboard lifetime. Old timers leave newer Stash copies and another app's clipboard content alone. Private clipboard entries are marked sensitive.
- Readable exports use a stable snapshot of the vault, avoiding inconsistent output if records change during the export.

Requires Android 8.0+. This is an optimized, non-debuggable APK signed with a production key.

**Fresh installation for users of the refreshed v1.0.0 GitHub APK:** its signing key is unavailable here, so v1.0.1 uses the available production key. Android will reject an in-place update from that build. Export and verify a portable encrypted backup before uninstalling, and keep its passphrase safe. Uninstalling deletes the vault and device key. After installing v1.0.1, restore the portable backup. A device-bound backup cannot survive uninstalling. The original v1.0.0 (internal code 13) shares the v1.0.1 key and can update normally.

This release also includes the recent portable-backup, privacy-policy and export-filtering changes from main.

Validation: all 80 unit tests passed, including regression coverage for clipboard expiry, bounded reads and oriented image sampling. Production build and release lint passed with zero errors. Emulator checks covered save/navigation responsiveness, note and password edits, password editor locking, rotated profile photos and preserving records across a same-key APK update.
