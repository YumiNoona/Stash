# Stash v1.8.0

- Add dedicated Aadhaar, PAN, voter ID, driving licence and Other ID wallet records, with distinct front/back layouts, typography, colour palettes and document-specific fields.
- Add Identity card to the Cards add menu. Imported card scans can suggest the identity type and labelled fields using bundled offline OCR. New and saved document review flows can create an identity card while retaining the original document.
- Keep editable names (including a local-language name), ID numbers, birth dates/year, relative names, addresses, constituency, licence issue/validity dates, blood group and vehicle classes as appropriate to the selected type.
- Preserve image/PDF originals and crop portraits, original QR images, signatures and issuer logos into explicit card slots. PDF crops support page selection. Stash does not generate official emblems, security features or QR credentials.
- Mask identity numbers in the collection. Require device credentials to reveal private details, copy fields, show original scans/QR or edit an existing identity card. Keep an edit draft behind a re-unlock screen after returning from the file picker.
- Keep all details and media inside the existing encrypted, local vault. Add no network permission or online lookup. QR signatures are not verified. Personal wallet layouts are labelled, and original scans remain separately accessible.
- Keep payment cards and existing vaults compatible. Sample OCR images before decoding and respect EXIF orientation in attachment previews.

Validation: 65 JVM tests pass; Android debug build succeeds; lint has 0 errors (47 warnings and 6 hints remain). Emulator validation uses fabricated identity details and a clearly labelled test source: PAN save/reopen, credential-protected editing, draft retention across file-picker relock, original image attachment, portrait/QR crops and saving, and inspection of all four layouts. The APK keeps the existing local debug signing identity for update compatibility.

Design references and limitations: docs/identity-card-design.md. OCR currently reads Latin text; local-language names can be entered manually. ID format checks are not authenticity verification. Device-bound backups remain device-bound.
